# Tip Calculator
A simple, single-page tip calculator. Enter the bill amount, tip percentage, and number of people to see tip, total, and per-person amounts update live. Includes a dark mode toggle.
## Run locally
```bash
npm install
npm run dev
```
Then open [http://127.0.0.1:45321](http://127.0.0.1:45321).
## Features
- Live calculation as you type
- Quick tip presets (10%, 15%, 18%, 20%)
- Split across any number of people
- Dark / light mode (remembers your choice)
