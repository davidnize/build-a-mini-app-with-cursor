# Tip Calculator

A simple, single-page tip calculator built with Cursor. Enter the bill amount, tip percentage, and number of people to see the tip, total, and per-person amounts update live. Includes a dark mode toggle.

**Live demo:** https://davidnize.github.io/build-a-mini-app-with-cursor/

## Run locally

No install needed. Download the repo and open `index.html` in your browser.

## Features

- Live calculation as you type
- Quick tip presets (10%, 15%, 18%, 20%)
- Split across any number of people
- Dark / light mode (remembers your choice)

## Built with

HTML, CSS, JavaScript, and Cursor
